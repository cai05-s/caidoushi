# JPEG 硬件解码资源评估

当前版本没有把 JPEG 解码器接入主显示链路，仍使用已经验证过的 BMP 读取和五帧 SDRAM 缓存。

TD 基线资源如下：

| 资源 | 使用量 | 利用率 |
|---|---:|---:|
| LUT | 15359 / 19600 | 78.36% |
| REG | 8832 / 19600 | 45.06% |
| BRAM | 32 / 64 | 50.00% |
| DSP | 9 / 29 | 31.03% |

JPEG 解码至少需要 Huffman 解码、反量化、IDCT、行缓存和 RGB 输出。由于 LUT 余量约 21.6%，本项目应先做独立综合和时序评估，再决定是否接入主链路。JPEG 模块必须输出与现有 BMP 链路兼容的 24 位像素流，并遵守 `write_data_ready` 背压；资源或时序超限时保持 BMP 版本不变。
