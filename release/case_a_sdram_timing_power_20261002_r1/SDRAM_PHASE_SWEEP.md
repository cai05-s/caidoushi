# SDRAM 相位扫描结果

保持 SDRAM 用户时钟和相移时钟均为 125 MHz，仅扫描 `sys_pll.v` 的 `CLKC2_CPHASE`：

| CPHASE | 全局 setup WNS | 结论 |
|---:|---:|---|
| 2 | -5.565 ns | 最佳，正式版本采用 |
| 3 | -6.565 ns | 原始基线 |
| 4 | -7.565 ns | 淘汰 |
| 5 | -8.565 ns | 淘汰 |

正式版本的 hold WNS 为 +0.011 ns，仍未完全时序闭合，但相位调整使最差 SDRAM DQ 输入路径改善约 1 ns。该路径逻辑级数为 0，主要受硬核 SDRAM 输入采样相位影响。

本版本同时在 `pcm_media_tone.v` 中增加音频空闲 clock enable：背景音乐关闭且 FIFO 排空时停止采样累加器和合成更新；应急音、夜间排空、音频恢复或 FIFO 有数据时保持活动。
