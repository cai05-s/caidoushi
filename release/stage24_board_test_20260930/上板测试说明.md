# 第2/4课上板测试版

请使用本目录的 **lab_ex5_stage24_20260930.bit**。目标芯片为安路 EG4S20BG256，视频接 **HDMI_B**。

此版包含专用应急按键、有界SD恢复、坏图跳过和帧缓存保护。RTL回归通过且完整构建已结束，**尚未上板**。布线后setup WNS为 **-6.565 ns**，hold WNS为 **+0.004 ns**；仍有SDRAM接口时序问题，不能称为稳定版或7×24验收通过。

## 按键定义

| 按键 | 功能 |
|---|---|
| KEY1 / A2 | 正常模式下一张；错误后重新尝试；空扫描结束后重新扫描 |
| KEY2 / B2 | 正常轮播暂停/继续；应急时忽略 |
| KEY3 / B1 | 按下一次进入应急，再按一次退出；一直按住只触发一次 |
| RESET / C1 | 全系统复位并刷新图片目录 |

每次按下/松开留至少0.1秒。默认开启常态轮播，切图完成后等待约3秒。应急退出恢复进入前的图片及轮播开关。亮度/对比度本阶段固定默认档，KEY3不再调参数。

数码管：正常为图片号1～4，应急为E，错误为F；OSD显示具体错误码。38=读取/加载无进展，3A=像素数量不完整，3D=缺少第4张应急图，3E=无可用图片，3F=转场确认超时；31～39中其他错误为BMP格式校验。

## 上板步骤

1. 使用当前TD下载工具将本目录bit下载到FPGA进行测试；本轮先做SRAM下载验证，尚未做Flash固化。
2. TF卡放入四张已知可读的RGB24 BMP，HDMI线接HDMI_B。应出现常态画面并轮播。
3. 按KEY2暂停，按KEY1换到另一张。按KEY3进入红框应急，再按KEY3退出，应恢复刚才图片且保持暂停。
4. 长按KEY3约3秒再松手：只切换一次；再次按下应返回。再快速交替进入/退出十余次，确认能恢复。
5. 用缺少第4张图的测试卡复位启动：应急提示仍出现，报3D，再按KEY3仍能退出。只有一张正常图时轮播不会换图。
6. 不插TF卡复位：初始化超时后显示错误；KEY3仍可切换红框状态。插回同一张卡后观察重新初始化与恢复；如果换卡或改变文件布局，请按RESET刷新目录。
7. 如测试读取中断，记录错误码以及按KEY3是否仍可退出；坏图最终失败应被跳过，所有图片失败应停止反复请求，修复文件并复位后重试。

若画面黑屏、花屏、无法恢复，请记录：是否显示E/F、OSD错误码、所按的板上键名、当前图片数量，以及是否只在换图/退出时发生。这些现象可用于区分控制问题与尚未收敛的SDRAM接口时序。

## 素材及版本边界

仍按物理扇区顺序扫描最多4张，第4张复用应急背景；本版没有独立的额外应急素材组。不同尺寸BMP保比例适配640×480，仍要求连续存储，未实现FAT32碎片链。本轮未增加告警音联动、FFT、拨码/LED/蜂鸣器、中文ROM或Flash启动。
