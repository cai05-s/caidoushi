# MQ-2 / MQ-135 烟雾传感器接线与演示

## 接线

- VCC 接开发板 3.3 V。
- GND 接开发板 GND。
- 模块 DO 接 J1 的 GPIOA_0，对应 FPGA 引脚 D14，也就是顶层端口 `smoke_do`。
- 调整模块上的电位器，使无烟时 DO 为高电平；超过阈值时常见模块会拉低 DO。

本版本按低电平有效处理，并加入约 1.5 秒触发确认和约 8 秒恢复确认。

## 演示流程

1. 上电后等待 MQ 模块预热和 DO 稳定。
2. 正常状态下屏幕播放普通图片，蜂鸣器关闭。
3. 用少量测试烟雾靠近传感器，使 DO 持续有效。
4. 约 1.5 秒后系统自动切换应急图片并启动蜂鸣器。
5. 移开烟源，等待传感器恢复并保持安全状态约 8 秒。
6. 系统自动返回原来的普通播放状态。

现场演示前应先用万用表确认 DO 的空闲电平和触发电平。若模块输出不是低有效，需要在 `top_tf_hdmi_audio.v` 中把 `ACTIVE_LOW` 改为 0 后重新编译。

KEY2 仍保留为人工应急按键；传感器仍处于告警时，人工解除不会立即清除自动告警。
