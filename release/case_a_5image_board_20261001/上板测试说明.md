# 案例A五图应急信息发布终端上板版

目标器件：HX4S20 / EG4S20BG256。HDMI接 HDMI_B。

## 按键和拨码

- KEY1=A2：常态轮播暂停/继续。
- KEY2=B2：进入/退出应急模式，加载第5张图片。
- KEY3=B1：重新扫描TF卡。
- KEY4=C1：常态模式切换下一张图片。
- SW3=C6：亮度模式。
- SW4=C5：高对比模式。
- SW1=C8：蜂鸣器硬件开关。

## TF卡素材

按文件名排序准备5张RGB24、非压缩BMP：第1～4张为常态内容，第5张为应急内容。运行：

`powershell
Set-Location 'C:\Users\27348\Desktop\lab_ex5_i2s\lab_ex5_i2s\doc\convert'
python .\sync_to_sd.py E: -n 5
`

FPGA仍按物理扇区扫描，要求文件连续存储；文件名只用于同步顺序，不能替代连续扇区约束。

## 现场操作

1. 先用 TD 将 case_a_5image_20261001.bit 下载到 SRAM。
2. 上电后观察前4张正常轮播。
3. 按 KEY4 手动切换常态图；按 KEY1 暂停/继续轮播。
4. 按 KEY2 应急：第5张图按帧边界硬切，顶部滚动中文指令，红框闪烁，HDMI告警音同步显示波形和峰值条。
5. 再按 KEY2 退出，恢复进入应急前的图片和轮播状态。
6. 更换TF卡后按 KEY3 重新扫描；少于5张或第5张损坏时数码管显示3D。
7. 验证断电重启、30分钟轮播和100次按键压力。
