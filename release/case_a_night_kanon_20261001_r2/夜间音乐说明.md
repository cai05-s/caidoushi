# 夜间音乐媒体

夜间模式由 SW3/SW4=00 选择，FPGA 从 FAT32 根目录按 8.3 短文件名读取
`KANON.WAV`，到 PCM 数据末尾后循环。SW2 在夜间不切换曲目；SW1 仍控制
背景静音，紧急音频优先级不变。

## 文件

| 文件 | 说明 |
|---|---|
| `KANON.WAV` | PCM signed 16-bit little-endian、双声道、48 kHz；142.187395 s；SHA256 `ee21bde1c69c614aca62cf51bf9ddb80ea777fd6e6235d87461471d8f16ebd56` |
| `source_canon_44k1_16b_mono.wav` | 用户原始文件备份；SHA256 `97debe08f8791b8d9f2d1f4d30bdd1fd956e6f9b5f1c1cdc143211de35fe48a4` |

将 `KANON.WAV` 复制到 FAT32 卡根目录，文件名保持大写。当前 FPGA 读取器
支持碎片化 FAT32 簇链，但要求卡在播放期间保持插入；缺卡、坏链或格式错误
会静音并上报音频错误，不阻塞图片链路。
